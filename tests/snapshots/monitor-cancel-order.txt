Cancel a specific order manually

Usage: quantforge monitor cancel-order [OPTIONS] --symbol <SYMBOL>

Options:
      --db <DB>
          SQLite database path [env: QF_DB=] [default: data/market.sqlite]
      --symbol <SYMBOL>
          
      --binance-base-url <BINANCE_BASE_URL>
          Binance API base URL. Use https://testnet.binance.vision/ for Spot testnet [env: QF_BINANCE_BASE_URL=] [default: https://api.binance.com/]
      --order-id <ORDER_ID>
          
      --client-order-id <CLIENT_ORDER_ID>
          
      --log-level <LOG_LEVEL>
          Log filter (trace, debug, info, warn, error or a full tracing filter expression) [env: QF_LOG=] [default: info]
      --yes
          
  -h, --help
          Print help
